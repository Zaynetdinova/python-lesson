# python-lesson

Учебный репозиторий: изучаю Python с нуля для работы с API, данными и AI-автоматизацией.

## Что внутри

Все файлы лежат в корне репозитория. В каждом уроке сначала короткая теория, затем решения заданий:

- `lesson1.py`: переменные, f-строки, условия, ввод данных
- `lesson2.py`: списки, словари, циклы
- `lesson3.py`: функции, чтение и запись JSON
- `lesson4.py`: запрос к API (курсы валют ЦБ РФ)
- `lesson5.py`: обработка ошибок (`try/except`), настройки из `.env`
- `lesson6.py`: pandas (таблицы, фильтры, сортировка, группировка, экспорт в CSV)
- `make_flats.py`: создаёт `flats.json` с тестовыми данными для уроков 6 и 9
- `lesson7.py`: мини-проект. Курсы валют из API ЦБ РФ, расчёт изменения за день в pandas и отправка сводки в Telegram
- `claude_utils.py`: общая функция `ask_claude` для запросов к Claude API с обработкой ошибок
- `telegram_utils.py`: общая функция `send_message` для отправки сообщений в Telegram
- `lesson8.py`: первые запросы к Claude API (system prompt, `max_tokens`, `usage`)
- `lesson8b.py`: мини-проект. Сводка курсов валют с комментарием Claude, отправка в Telegram
- `lesson9.py`: структурированный JSON-ответ (разбор заявок клиентов в `leads.json`) и tool use (Claude вызывает функции: ипотечный платёж, цена за м², поиск квартир в `flats.json`)
- `lesson10.py`: мини-проект «классификатор заявок» (см. ниже)
- `classifier.py`: логика разбора заявки через Claude (промпт, проверка ответа, функция `classify_text`), общая для скрипта и API
- `app.py`: API на FastAPI (урок 11, см. раздел «API»)
- `requirements.txt`: список зависимостей

## Мини-проект: классификатор заявок (lesson10.py)

Скрипт разбирает входящие заявки клиентов агентства недвижимости:

1. Читает заявки из `inbox.json` (вымышленные тексты для примера).
2. Пропускает уже обработанные (по `id`), поэтому повторный запуск ничего не дублирует.
3. Просит Claude вернуть для каждой заявки JSON: имя, бюджет, число комнат, категорию (`buy`, `rent_out`, `consult`, `spam`), срочность и краткое резюме.
4. Проверяет ответ модели в коде (`validate_lead`): допустимые значения категории и срочности, тип бюджета. Текст заявки считается данными, а не инструкциями.
5. Сохраняет результат в `processed_leads.json`.
6. Считает сводку в pandas и отправляет в Telegram: статистику, срочные заявки и сообщения о заявках, которые не удалось разобрать.

Заявки, которые не удалось разобрать, в файл результатов не попадают и обрабатываются заново при следующем запуске.

## API

Классификатор заявок доступен как сервис на FastAPI (`app.py`). Он принимает текст заявки и возвращает разбор в формате JSON.

Запуск (нужны `ANTHROPIC_API_KEY` и `API_ACCESS_KEY` в `.env`):

```
uvicorn app:app --reload
```

Документация (Swagger): http://127.0.0.1:8000/docs

Адреса:

| Метод и адрес | Что делает | Нужен ключ |
|---|---|---|
| `GET /health` | проверка, что сервис работает | нет |
| `POST /classify` | разбирает текст заявки | да |
| `GET /leads` | возвращает заявки из `processed_leads.json` | да |

Ключ передаётся в заголовке `X-API-Key`. Без ключа сервер возвращает 401. Если в `.env` нет `API_ACCESS_KEY`, сервер не запустится.

Пример запроса:

```
curl -X POST http://127.0.0.1:8000/classify \
  -H "Content-Type: application/json" \
  -H "X-API-Key: ваш_ключ_доступа" \
  -d '{"text": "Ищу однушку до 6 млн, срочно", "notify": false}'
```

Если передать `"notify": true`, то по срочной заявке (не спам) в Telegram уйдёт сообщение.

Коды ответов: `200` успех, `401` неверный или отсутствующий ключ, `422` неверный запрос (например, пустой или слишком короткий `text`), `502` модель не вернула пригодный разбор.

Сервис рассчитан на локальный запуск (`127.0.0.1`). Для публикации в интернете понадобились бы ограничение частоты запросов, HTTPS и лимиты расходов.

## Как запустить

```
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python lesson5.py
```

Для Windows активация окружения: `.venv\Scripts\activate`.

Для уроков 6 и 9 сначала создайте данные, затем запустите нужный урок:

```
python make_flats.py
python lesson6.py
```

Для классификатора заявок:

```
python lesson10.py
```

## Настройки

Скрипты, которым нужны ключи, читают их из файла `.env` в корне проекта (он не хранится в репозитории). Создайте его сами с нужными переменными:

```
TELEGRAM_BOT_TOKEN=ваш_токен_бота
TELEGRAM_CHAT_ID=ваш_chat_id
ANTHROPIC_API_KEY=ваш_ключ_claude_api
API_ACCESS_KEY=придуманный_вами_длинный_случайный_ключ
```

- `TELEGRAM_BOT_TOKEN` выдаёт @BotFather в Telegram. Перед запуском нужно открыть своего бота и нажать Start.
- `ANTHROPIC_API_KEY` создаётся в Claude Console (раздел API Keys). Использование API оплачивается отдельно от подписки.
- `API_ACCESS_KEY` защищает собственный API (урок 11): это любой длинный случайный набор символов, который вы придумываете сами.
- Для уроков 7 и 8б нужны Telegram-переменные, для уроков 8-9 нужен ключ Claude, для урока 10 нужны первые три, для API нужны `ANTHROPIC_API_KEY` и `API_ACCESS_KEY` (для уведомлений ещё и Telegram-переменные).
