# python-lesson

Учебный репозиторий: изучаю Python с нуля для работы с API, данными и AI-автоматизацией.

## Что внутри

Все файлы лежат в корне репозитория:

- `lesson*.py`: скрипты по урокам (переменные, условия, списки и словари, функции, JSON, запросы к API, обработка ошибок, `.env`)
- `homework*.py`: решения домашних заданий
- `lesson5.py`: запрос курсов валют ЦБ РФ с обработкой ошибок и чтением настроек из `.env`
- `requirements.txt`: список зависимостей

## Как запустить

```
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python lesson5.py
```

Для Windows активация окружения: `.venv\Scripts\activate`.

## Настройки

Скрипты, которым нужны ключи, читают их из файла `.env` в корне проекта (он не хранится в репозитории). Создайте его сами, например:

```
MY_API_KEY=ваш_ключ
```
